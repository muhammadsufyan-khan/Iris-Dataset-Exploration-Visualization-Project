# 🌸 Iris Dataset Exploration & Visualization Project

## 📌 Problem Statement
The objective of this task is to **load, explore, analyze, and visualize** the Iris dataset to understand trends, relationships, and data distributions.


## 🎯 Task Objectives
- Load and inspect the dataset using Pandas.
- Explore structure, summary statistics, and data types.
- Visualize the dataset using scatter plots, histograms, box plots, and pair plots.
- Provide explanations and insights.
- Ensure clean and documented code.



## 📂 Project Structure
```
Iris-EDA-Project/
│
├── README.md                # Project documentation & submission report
```

## 📊 Dataset Used
**Iris Dataset** (via Seaborn)
- 150 samples
- 4 numeric features
- 3 flower species

Features:
- sepal_length
- sepal_width
- petal_length
- petal_width

Target:
- species


## 🧪 Methods & Visualizations Applied
### **✔ Scatter Plot**  
Reveals feature relationships and species separation.

### **✔ Histogram**  
Shows distribution of sepal length.

### **✔ Box Plot**  
Identifies outliers in numeric features.

### **✔ Pair Plot**  
Provides full multi-dimensional view of class separation.



## 📝 Key Insights & Findings
- Setosa species forms a completely separate cluster.
- Petal-based features are highly discriminative among species.
- Versicolor and Virginica show partial overlap.
- No missing values in the dataset.
- Feature ranges vary significantly.
